B Annuaire — générateur de config

Le crawler d'annuaire tourne en ligne de commande (Crawlee). Remplis les sélecteurs CSS de la page cible (inspecte-la avec les DevTools : clic droit → Inspecter), copie le JSON, et lance la commande.

Sauve ce JSON dans tools/scraper/configs/mon-annuaire.json, puis lance :
node crawlee-directory.mjs --config configs/mon-annuaire.json --out ../../prospection/mon_annuaire.csv
