C Importer le catalogue vers nexusmarket.sn

  
Trois familles, détectées automatiquement d'après les colonnes du CSV :

  
    
    
  • 🚌 Transport (colonnes Compagnie + Type_vehicule) → tables
      transport_lines + transport_recurrences. Une ligne par trajet, une ou
      plusieurs récurrences (quotidien, plusieurs/jour, hebdo à jours fixes, sur demande, jours d'événement).
    • 
    
  • 🔑 Location (colonnes Categorie + Prix_jour_fcfa) → un compte annonceur
      (vendeur) par téléphone + un produit is_rental (specs rental_specs).
    • 
    
  • 🏠 Immobilier (colonnes Transaction + Type_bien) → un compte annonceur
      + un produit is_realestate (specs realestate_specs). Catégorie = « Immobilier ».
    • 
  

  
💶 Convention monétaire : les prix des CSV sont en FCFA. Location/Immobilier sont des
    products → price est stocké en EUR (÷ 655,957, convention de la pile) ; les
    montants FCFA d'origine restent dans les *_specs. Transport reste en FCFA (comme le covoiturage).

D Produits catalogue → boutique d'un vendeur (avec marge)

  
Importe une liste de produits « normaux » (mode, électronique, maison, beauté…) issue de la
    prospection, ajuste les prix de vente pour te faire une marge dans le tableau, puis exporte-les vers
    la table products attribués à un compte vendeur. Tout ce que le site affiche est inclus :
    nom, catégorie, photo(s), description, prix, prix barré, stock.

  
💶 Prix des CSV en FCFA → stockés en EUR (÷ 655,957) dans price /
    original_price. Colonnes lues :
    Nom, Categorie, Prix_achat_fcfa, Prix_vente_fcfa, Prix_original_fcfa, Stock, Description, Image_url,
    Images, Marque, Etat, Region, Vendeur, Telephone — seuls Nom + un prix (achat ou vente) sont requis.
    Le prix d'achat sert de base au calcul de marge ; le prix de vente est ce qui est publié.
