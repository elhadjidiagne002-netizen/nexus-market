Étapes dans Google Cloud Console

  1. Allez sur console.cloud.google.com et créez un projet.
  2. Menu API et services → Bibliothèque : activez People API.
  3. Écran de consentement OAuth : type "Externe", ajoutez votre propre email comme utilisateur test.
  4. Identifiants → Créer des identifiants → ID client OAuth, type Application Web.
  5. Dans Origines JavaScript autorisées, ajoutez l'adresse depuis laquelle vous ouvrirez ce fichier (ex. http://localhost:8080).
  6. Copiez l'ID client généré (il se termine par .apps.googleusercontent.com) et collez-le ci-dessous.

Identifiant & connexion

⚠️ Ce fichier doit être ouvert via une adresse http:// ou https://, pas en double-clic direct (file://) — Google bloque l'authentification sur ce protocole. Le plus simple : ouvrez un terminal dans le dossier du fichier puis lancez python3 -m http.server 8080, et allez sur http://localhost:8080 dans votre navigateur.
L'ID client n'est pas une donnée secrète (il est conçu pour être visible côté navigateur) — vous pouvez l'inclure sans risque dans vos sauvegardes exportées.
